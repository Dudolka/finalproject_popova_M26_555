# ValutaTrade Hub — аудит соответствия заданию МИФИ

Основание: исходный документ «Проект 3», проект из Git-коммита `3483c51`,
предоставленный архив `ValutaTrade_Hub_source.zip`.

## Выполненные корректировки

1. **Регистрация:** `UserService.register()` сохраняет пустой портфель с `user_id`
   вместе с новой учётной записью; при ошибке сохранения портфеля выполняется
   компенсирующее восстановление `users.json` (best effort; два JSON-файла
   не являются полноценной транзакционной базой данных).
2. **Реестр валют:** `GBP` и `SOL` доступны в Core и согласованы со списками
   Parser Service.
3. **Команда `get-rate`:** при отсутствующей или просроченной валютной паре
   сначала пытается обновить курсы. При сбое показывает причину и не помечает
   старый курс как актуальный.
4. **`show-rates --top N`:** выборка ограничена криптовалютами; пересчёт по
   указанной базе выполняется после валидации.
5. **Портфель:** показывает стоимость отдельного кошелька в выбранной базовой
   валюте, если доступны необходимые курсы, а также общую стоимость.
6. **Покупка и продажа:** показывает расчётную USD-сумму по доступному кэшу и
   остатки валют после совершённой сделки. Это справочная оценка из локального
   кэша, не неизменяемая запись цены исполнения.
7. **Декомпозиция:** расчёт кросс-курса вынесен в `core/utils.py`.
8. **SettingsLoader:** добавлен метод `get(key, default)`.
9. **Точка запуска:** добавлен необязательный `main.py` наряду с установленной
   командой `uv run valutatrade-hub`.
10. **Тесты:** добавлено 13 новых тестов (исходно 330; в изменённой версии 343).
11. **Демонстрация:** добавлены `scripts/record_demo.py` и
   `demo/ValutaTrade_Hub.cast`. Это asciinema v2, созданная с помощью
   реальных методов CLI и временного хранилища, но с **симуляцией ответов API**.
12. **Документация:** актуализирован README.

## Проверки, выполненные в среде подготовки

- Синтаксическая проверка Python: успешно.
- `python -m unittest discover -s tests -q`: **343 теста, OK**.
- Версия интерпретатора проверки: **Python 3.13.5**, не пользовательский Python 3.12.
- В среде отсутствуют настоящая библиотека `prettytable` и Ruff; для
  выполнения тестов использована **временная минимальная подмена PrettyTable**
  исключительно в `PYTHONPATH` за пределами архива. Поэтому этот прогон не
  заменяет запуск на macOS с полноценными зависимостями.
- Сгенерированная офлайн-демонстрация проверена как корректный NDJSON
  формата asciinema v2; на Mac её следует перезаписать из настоящей среды
  `uv run python scripts/record_demo.py` для табличного вывода PrettyTable.

## Обязательно проверить на MacBook

```bash
uv sync
uv run ruff format .
uv run ruff check .
uv run ruff format --check .
uv run python -m unittest discover -s tests -q
uv run python scripts/record_demo.py
```

После этого требуется проверить реальную сетевую интеграцию с CoinGecko и,
при наличии ключа, ExchangeRate-API. В среде подготовки реальный сетевой
доступ **не проверялся**. Убедиться, что статус курсов свежий и котировки
пары вида `EUR_USD` означают USD за 1 EUR.

## Границы результата

- Сдача на 50/50 не может быть гарантирована: оценку выставляет преподаватель.
- Демо с подставными API-ответами подтверждает основные операции и внутреннюю
  интеграцию компонентов, но не заменяет живую проверку HTTP.
- Рабочие JSON-файлы и журнал не включены в пакет изменений. Скрипт демонстрации
  использует только временную папку и фиктивные реквизиты.
